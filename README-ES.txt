MEDITACIÓN PARA MEJORAR EL MUNDO — SITIO ESTÁTICO INDEPENDIENTE

Este paquete es una página web estática. No requiere Higgsfield, React, Node, servidores propios ni pagos de hosting.

PUBLICAR GRATIS EN GITHUB PAGES
1. Crea o inicia sesión en https://github.com
2. Crea un repositorio público llamado EXACTAMENTE: TUUSUARIO.github.io (sustituye TUUSUARIO por tu nombre de usuario real de GitHub).
3. Descomprime este ZIP en tu computadora.
4. Sube al repositorio el archivo index.html, styles.css y la carpeta assets completa. Es importante que index.html quede en la raíz del repositorio.
5. En GitHub abre Settings > Pages. En Build and deployment elige Deploy from a branch. Selecciona la rama main y la carpeta /(root), guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección será https://TUUSUARIO.github.io

No es un dominio .com, pero sí una dirección gratuita de GitHub Pages. El sitio permanece publicado mientras conserves el repositorio y cumplas las condiciones de GitHub Pages. No hay una garantía de permanencia absoluta ni un SLA de pago.

CONTENIDO
- index.html: estructura y contenido completo.
- styles.css: diseño urbano neón morado, azul, magenta y negro.
- assets/: fotografías, texturas y video locales.
- El formulario/registro abre Luma: https://luma.com/ownv17vm

PERSONALIZACIÓN
- Para reemplazar el espacio de Luis, edita la sección id="luis" de index.html.
- Para cambiar fecha, horario o precio, edita la sección id="registro" y las preguntas frecuentes.
- Para actualizar colores, modifica las variables al inicio de styles.css y las reglas URBAN NEON EDITION.
